# 테스트 개선 목록

자동 검사(브라우저 E2E)에서 기능 문제가 아니라 검사 방식 때문에 생긴 실패와 관리 문제를 모은다. 고치면 항목 옆에 날짜와 함께 ‘해결’을 적는다.
