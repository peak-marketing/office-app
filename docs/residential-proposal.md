## 단계 제안

집 안의 벽·방문이 필요한지가 단계를 나누는 기준입니다.

### 1단계 · 원룸·오피스텔 (집 안 벽 없이 바로 가능)

- 공간 종류 고르기(사무실 / 주거) → 주거 유형(원룸·오피스텔)
- 주거 입력 항목, 주거 가구 목록, 주방·욕실·세탁 설비 위치(자동 제안 / 고객 확인)
- 주거 견적 항목 세트와 업체 화면의 주거 항목
- 공간 탐색에 주거 유형 필터와 주거 예시 사례 3~5건(3D 예시로 표시)

지금 만든 바깥 벽 입력·도면 따라 그리기·편집·요청·비교를 그대로 씀

### 2단계 · 투룸·쓰리룸·빌라 (집 안의 벽·방문 필요)

- 도면 따라 그리기에 집 안의 벽·방문 추가(지금 ‘후속 범위’로 표시된 기능)
- 방 이름과 방별 면적, 방 단위 공사 범위(예: 욕실만, 주방만)
- 방별 가구 배치와 방 단위 검사(가구가 방 밖·문 앞을 막는지)

집 안의 벽·방문 그리기는 사무실의 기존 구조 재현에도 쓰임

### 3단계 · 아파트 (평형 도면 틀)

- 자주 쓰는 아파트 구조(예: 24평 3룸·32평 3룸)를 틀로 고른 뒤 치수만 고치기
- 발코니 확장 여부, 관리 규약·공사 가능 시간 확인 항목
- 주소로 아파트 도면을 찾는 기능은 지금처럼 별도 후속(도면 자동 인식과 함께)

틀은 출발점일 뿐이며, 실제 집과 다른 부분은 고객이 고치고 업체가 실측으로 확인

## 그대로 유지하는 것

- 비공개 경쟁입찰형 시공 매칭: 업체끼리 금액·제안 비공개, 최저가 자동 낙찰 없음, 같은 요청 기준끼리 비교
- AI 공사비 추정 없음, 금액 미정은 0원이 아닌 ‘현장 확인 필요’
- 예시는 예시라고 표시(3D 예시와 실제 시공 사례 구분), 실적·후기 지어내지 않음
- 자동 검사에 걸린 곳이 없어도 ‘시공 가능’이라고 하지 않음. 법규(발코니 확장 등)는 판정하지 않고 업체 확인 항목으로 안내
- 지금 사무실 테스트 기준 버전과 테스트 서버는 그대로 두고, 주거 작업은 별도 사본에서 진행

## 정해 주실 것

1. **주거를 언제 시작할지** — A) 1단계(원룸·오피스텔)를 사무실 테스트와 병행해 별도 사본에서 시작  B) 지금 착수 조건대로 사무실 흐름 검증과 집 안 벽·방문 개발 뒤 시작
   - 제안: A 권장. 이 경우 1단계에 한해 착수 조건 ①은 ‘병행’으로, ②는 2단계 조건으로 옮깁니다. 테스트 기준 버전은 건드리지 않고, 사무실 테스트에서 막힘이 나오면 그 수정을 먼저 합니다
2. **1단계 범위** — 원룸·오피스텔만 / 빌라(원룸형) 포함
   - 제안: 원룸·오피스텔만으로 시작
3. **로드맵 순서** — 지금: 커뮤니티 1 → 주거 3D 2 → 상품 판매 3 → 상품 3D 배치 4
   - 제안: 주거 1단계를 커뮤니티와 같은 우선순위로 올리고, 주거 2·3단계는 지금 2순위 자리 유지
4. **주거 견적 항목** — 위 13개 초안
   - 제안: 참여 업체 의견을 받아 확정
5. **주거 입력 항목** — 위 요청 입력 초안
   - 제안: 필수는 주거 유형·면적·방·욕실 수·공사 범위만, 나머지는 선택
6. **주거 예시 사례** — 3D 예시로 시작 / 실제 시공 사진 확보 뒤 시작
   - 제안: 3D 예시 3~5건으로 시작하고 ‘3D 예시’로 표시, 실제 사례가 생기면 교체
7. **주거 업체 모집** — 사무실 업체 중 주거 가능 업체 / 주거 전문 업체 별도 모집
   - 제안: 주거 1단계 테스트용으로 2~3곳
8. **주소 공개 시점** — 지금처럼 방문 요청한 업체에 공개 / 집은 방문 일정 확정 뒤 동·호수 공개
   - 제안: 집은 방문 일정 확정 뒤 동·호수 공개
