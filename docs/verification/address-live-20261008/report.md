# 도로명주소 검색 실제 연동 확인

2026-10-08, `platform-next`의 기존 주소 검색 기능에 전달받은 개발 승인키를 설정하고 실제 API 호출을 확인했습니다.

- 승인키 저장: 서버 전용 `.env.local`, 파일 권한 600. Git 제외 파일입니다.
- 공식 API: `https://business.juso.go.kr/addrlink/addrLinkApi.do`
- `갈매스타힐스`: 아파트(산마루로 46)와 상가동(산마루로 44)이 각각 검색됩니다.
- `구리시 산마루로 46`: 갈매스타힐스 1건, 지번 갈매동 651, 우편번호 11902.
- 존재하지 않는 검색어: 결과 0건. 예시 주소로 대체하지 않습니다.

공식 API 직접 확인 3건이 모두 정상 응답했습니다. 서비스의 `searchAddress` 코드도 별도 임시 DB에서 실행했고, 실제 주소 반환·검색 결과 없음·짧은 검색어 거절·키 비노출을 포함한 5개 확인을 통과했습니다. 기존 고객·업체 데이터는 사용하거나 수정하지 않았습니다.

이 승인키는 도로명주소 검색용입니다. 동·층·호 후보 조회는 상세주소 검색 API의 별도 승인키로 확인해야 합니다. 건축물대장과 평면도 공급 서비스는 이번에 연동하지 않았습니다. 서버를 새로 시작하면 저장된 설정을 읽습니다.

재검증 명령(`platform-next` 폴더):

```sh
node --env-file=.env.local --import tsx ../output/address-live-20261008/verify.mts
```

검증 코드는 키를 파일에서 읽으며 실행 결과에는 키를 출력하지 않습니다. 원본 응답 전체 대신 주소와 결과 수만 기록했습니다.
