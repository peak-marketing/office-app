## P1 · 도면 닫기 오류 (막힘) — 수정

- 원인: 첫 클릭은 반올림하지 않고 이후 클릭만 0.1px로 반올림해, 직각으로 맞춘 좌표 사이에 미세한 차이가 생겼고 mm 반올림 뒤 1mm 기운 벽이 됐습니다.
- 수정(`lib/space/trace.ts`, `TraceTool.tsx`):
  - 첫 점을 포함해 모든 꼭짓점을 같은 0.1px 격자에 둡니다.
  - 직각 맞춤을 화면과 서버 검사가 같은 함수(`nextTracePoint`)로 합니다.
  - 닫을 때 1px 안의 차이는 같은 줄로 맞추고(`rectifyOrtho`), 실제로 기운 벽은 그대로 거절합니다.

## P2 · 새 배치 전송 뒤 견적 비교의 기본 기준 — 수정

- 비교 화면의 기본은 언제나 가장 최근에 보낸 요청(r2)입니다. 최신 제안이 없으면 ‘업체가 변경 내용을 확인 중입니다’로 안내합니다.
- 이전 견적은 ‘이전 요청 기준 제안 보기 · r1 · N건’으로 따로 엽니다(제안이 모두 옮겨진 뒤에도 r1 기록은 열 수 있음). 이전 요청을 보는 중에는 ‘최신 요청으로 돌아가기’가 있습니다.
- 기준 배치 표시와 도면 링크는 고른 요청 기록의 배치를 따릅니다(r2 → 배치 버전 4, r1 → 배치 버전 2).
- 상단 ‘지금 할 일’, ‘제안 비교’ 탭 숫자, 한눈에·내 공간 목록의 제안 수도 최신 요청 기준으로 셉니다.
