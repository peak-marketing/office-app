# 건축물대장 실제 연결 확인 — 2026-10-08

`platform-next`에 전달받은 건축HUB 인증키를 연결하고, 실제 주소·상세주소·건축물대장 API를 이어서 확인했습니다. 키는 Git에서 제외된 서버 전용 `.env.local`에 저장했으며 파일 권한은 600입니다. 공개 파일과 Git 대상 파일에 키가 없는 것을 검사했습니다.

## 실제 조회 결과

- 주소: 경기도 구리시 산마루로 46 (갈매동, 갈매스타힐스)
- 선택: 401동 → 1층 → 102호
- 선택 호의 전유면적: **74.94㎡** (공용면적 제외)
- 선택 동의 표제부: 지상 27층·지하 1층, 129세대, 연면적 13,626.34㎡, 사용승인일 2017.08.07
- 세대수·층수·연면적은 401동 수치입니다. 단지 전체 수치로 표시하지 않습니다.
- 이 응답은 평면도·벽·방 위치나 해당 호의 도면 타입을 확인한 결과가 아닙니다. 면적만으로 기존 도면 타입이나 직사각형 치수를 고르지 않습니다.

## 고친 처리

- 포털의 인코딩된 키를 중복 인코딩하지 않습니다. 일반 키도 지원합니다.
- 표제부를 전부 읽고 선택한 동을 일치시킵니다. 다른 동의 첫 결과를 사용하지 않습니다.
- 상세주소의 `102호`를 건축물대장의 `102`로 변환하고, 표제부에서 확인한 정확한 동 이름으로 조회합니다.
- 같은 지번·동·호의 전유부만 합산합니다. 공용부·다른 동·호·중복 또는 불명확한 면적은 자동 입력하지 않습니다.
- 실제 확인 중 HTTP 200 빈 응답과 서비스 연결 실패가 있었습니다. 연결·빈 응답 오류는 최대 두 번 재시도하고, 계속 실패하면 다시 조회하거나 직접 입력하도록 안내합니다. 인증 오류는 재시도하지 않습니다.
- 면적 조회에 실패해도 이미 확인된 건물 정보는 유지합니다. 누락 면적을 0㎡나 예시 면적으로 바꾸지 않습니다.
- 고객이 선택한 동·호와 인증키를 조회 기록에 남기지 않습니다.
