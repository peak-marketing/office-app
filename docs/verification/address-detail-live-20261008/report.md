# 상세주소 실제 연동 결과

확인일: 2026-10-08(한국 시간). 작업 위치: `platform-next`. 기존 3100용 코드와 고객·업체 데이터는 사용하거나 수정하지 않았습니다.

## 실제 조회

- 도로명주소: 경기도 구리시 산마루로 46(갈매스타힐스).
- 상세주소 동 목록: 401동부터 412동까지 12개.
- 401동 층·호 목록: 129건. 예를 들어 1층 102호를 실제 선택할 수 있습니다.
- API가 제공한 건물 식별값을 대조한 뒤 목록을 표시합니다. 다른 건물·동 응답, 불완전한 목록은 사용하지 않습니다.
- 호수 수록은 건물마다 다르며, 도면·호별 평형 타입 제공을 뜻하지 않습니다.

## 구현

로그인 → 주소 검색 → 건물 선택 → 동 → 층 → 호 선택을 연결했습니다. 조회가 안 되거나 목록에 원하는 정보가 없으면 직접 입력, 도면·치수 입력, 상담 경로가 남습니다. 동 변경 시 이전 호 선택과 조회 결과를 지웁니다. 선택한 동·층·호는 조회에만 쓰며 조회 기록에는 건물 식별값·건수·상태만 남깁니다.

건축물대장 키는 아직 없으므로 실제 주소에 예시 면적·준공일을 보여주거나 상담 입력값으로 넘기지 않습니다. 상세주소 조회와 등록 도면 찾기는 별도 기능이며, 동·호만으로 특정 도면을 자동 선택하지 않습니다.

승인키는 `.env.local`에 서버 전용으로 저장했습니다. 환경 파일과 테스트 빌드를 Git에서 제외했고, Git에 포함될 파일에 두 승인키가 들어 있지 않은 것도 확인했습니다.

## 검사 결과

- API 응답·오류·미수록·식별값 대조·키 비노출 계약 검사: 15개 통과.
- 실제 서비스 코드와 실제 승인키 조회: 6개 통과.
- 실제 Chrome PC·390px 휴대폰 흐름: 26개 통과.
- 기존 고객·업체·운영자 공통 흐름: 69개 통과.
- TypeScript·변경 파일 ESLint 통과. Webpack 운영 빌드 성공.

발급 직후 서비스 코드 첫 조회는 실패했으며, 재확인과 브라우저 검사에서는 정상 조회됐습니다. 최초 실패의 원인은 확정하지 않았습니다. 개발 환경의 Turbopack 빌드는 포트 생성 권한 오류로 실패하여 공식 `--webpack` 옵션으로 빌드하고 그 결과물에서 브라우저 검사를 했습니다.
