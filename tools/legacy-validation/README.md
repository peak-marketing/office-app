# 이전 검증 도구 보관

임시 폴더에 있던 주거 통합 검사와 코드·데이터 지문 비교 도구를 저장소로 옮겼습니다. 현재 자동 회귀 검사의 시작점은 `tests/e2e/`와 `scripts/e2e.mjs`입니다. 이 폴더는 과거 결과를 재현하거나 비교할 때 참고합니다.

| 파일 | 역할 |
| --- | --- |
| `home-e2e.cjs` | 주거 1차 당시 전체 흐름. 현재 실행판은 `tests/e2e/home.cjs` |
| `livehome.cjs` | 당시 주거 예시·신청 화면 열람 검사 |
| `pagecap.cjs` | 역할별 페이지 글자와 파일 응답 비교 자료 수집 |
| `pagediff.py` | 페이지 비교 JSON 차이 확인 |
| `datahash.mjs`, `srchash.mjs` | 데이터·소스 지문 비교 |
| `photo1.jpg`, `plan1.jpg` | 시연 검사에 사용한 예시 이미지 |

이전 도구에는 Mac Chrome 경로와 당시 예시 ID가 남아 있습니다. 현재 서비스에 바로 실행하지 말고 코드의 환경 변수(`B`, `DB`, `OUT` 등)를 확인해 격리된 데이터 사본에서 사용합니다. 페이지 수집 도구도 로그인 기록을 만들 수 있으며, 출력에는 프로젝트 정보나 공유 링크가 포함될 수 있으므로 결과를 자동으로 Git에 올리지 않습니다.
